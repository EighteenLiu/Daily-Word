日报生成工具 使用手册

GitHub 地址：
https://github.com/EighteenLiu/Daily-Word.git

一、工具用途
本工具用于根据垃圾分类检查台账自动生成各街道检查日报。
支持选择 Excel 台账文件（.xls / .xlsx）和 Word 日报模板（.docx），批量输出各街道日报。

二、运行环境要求
1. 操作系统：Windows。
2. 如果输入台账是 .xls，目标电脑需要安装 Microsoft Excel，程序会调用 Excel COM 转换为 .xlsx。
   如果输入已经是 .xlsx，通常不需要转换。
3. 不需要在目标电脑单独安装 Python。
   exe 发布版已经内置 Python 运行环境和主要依赖。

三、发布包目录说明
发布包目录一般为：
release\日报生成工具\

目录内主要文件：
1. 日报生成工具.exe
   双击启动图形界面。
2. input\
   建议放置台账和日报模板。
3. output\
   生成结果默认输出到这里。
4. 使用手册.txt
   当前说明文件。

四、基本使用步骤
1. 双击“日报生成工具.exe”。
2. 在“台账”一栏选择当天检查台账（.xls 或 .xlsx）。
3. 在“街道日报模板”一栏选择街道日报模板（.docx）。
4. 如需生成日汇总报告，勾选“同时生成每日汇总和垃圾分类工作日报”，并选择：
   垃圾分类日报模板：例如 input\5月17日垃圾分类工作日报.docx
   每日汇总模板：例如 input\每日汇总情况(10).docx
5. 在“图片压缩”一栏选择压缩程度：
   标准为推荐设置；轻度更清晰；强力文件更小；不压缩会保留原图插入，文件可能很大。
6. 点击“生成日报”。
7. 界面按钮显示“正在生成...”时请等待，不要重复点击。
8. 日志显示完成后，到 output 文件夹查看生成结果；日汇总默认在 output\每日总结\每日总结（日期）\ 中。

五、模板说明
1. 推荐使用 docxtpl / Jinja2 格式的 Word 模板。
2. 模板中可使用 {{ ... }} 变量和 {%p ... %} 段落控制语句。
3. 如果选择的模板不含 Jinja 标签，程序会使用内置规则生成 Word。
4. 模板路径可以是 input 文件夹内的模板，也可以手动选择其他位置的模板。

六、迁移到其他电脑
1. 直接复制整个 release\日报生成工具 文件夹到目标电脑。
2. 不要只复制 exe 文件，必须连同旁边的依赖文件夹一起复制。
3. 在目标电脑上双击“日报生成工具.exe”运行。
4. 如果处理 .xls 台账，目标电脑需要安装并能正常启动 Microsoft Excel。

七、常见问题
1. 提示模板不存在：
   重新点击“选择模板”，确认选择的是实际存在的 .docx 文件。

2. 提示台账不存在：
   重新点击“选择台账”，确认选择的是 .xls 或 .xlsx 文件。

3. .xls 无法转换，或提示“被呼叫方拒绝接收呼叫”：
   Excel COM 报错通常是 Excel 正忙或拒绝自动化调用造成的。请先关闭所有 Excel 窗口、Excel 弹窗、保护视图提示和正在编辑的单元格，再重新生成。
   如果仍然失败，可以手动用 Excel 打开 .xls，另存为 .xlsx，然后在工具里选择这个 .xlsx 台账。

4. 图片没有生成或数量异常：
   请确认台账中的图片实际嵌入在 Excel 文件中，而不是外部链接或截图引用。

5. 生成的 Word 文件过大：
   在界面选择“标准”或“强力”图片压缩。程序仍会保留原始提取图片，日报中插入的是临时压缩后的图片副本。

6. Word 文件正在被占用：
   如果模板或输出文件正在被 Word 打开，请先关闭 Word 后重新生成。

八、重新打包方法
如果需要从源码重新生成 exe，在项目根目录运行：
powershell -ExecutionPolicy Bypass -File packaging\build_release.ps1

打包完成后，发布目录为：
release\日报生成工具\
